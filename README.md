# SHIVAM Profile

A standalone, responsive profile page inspired by the structure of modern one-page profile cards.

## Included
- Full-screen uploaded MP4 background
- Uploaded MP3 music
- Click-to-enter screen
- Glass profile card
- Avatar/status area
- UID + bio
- Social buttons
- View counter
- Music controls
- Mobile responsive layout
- No framework or npm install required

## Run
Open `index.html` in a browser.

For best results, use a local server:
- VS Code Live Server, or
- `python -m http.server 8080`

Then open `http://localhost:8080`.

## Customize
Edit `index.html` for:
- username
- UID
- bio
- social links
- music title

Replace:
- `assets/background.mp4`
- `assets/music.mp3`

with your own files if needed.
